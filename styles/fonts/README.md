# Self-hosted fonts

These unmodified WOFF2 variable font binaries are distributed under their accompanying SIL Open Font Licenses.

| Family | Source | Version |
| --- | --- | --- |
| Instrument Sans | `@fontsource-variable/instrument-sans` | 5.3.0 |
| Noto Sans SC | `@fontsource-variable/noto-sans-sc` | 5.3.1 |
| JetBrains Mono | `@fontsource-variable/jetbrains-mono` | 5.3.0 |

`../fonts.css` declares the approved family names and the 400–600 weight range. Noto Sans SC is split into the original Unicode subsets so browsers fetch only the required character ranges. The complete font payload is local; there are no runtime font CDN requests.
