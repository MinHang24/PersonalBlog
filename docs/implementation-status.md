## 安全门槛

当前可见工具没有提供公开的实时 Make 成员资格校验接口。原生
Payload `auth: true` 不能证明密码登录与成员资格组合成立。保留平台
Admin 认证，不改写平台 OAuth、不新增公开账户、不自行制造成员白名单。
在该能力可验证之前，新 CMS 特权入口采取失败关闭；不把该分支报告为完成。

现有唯一 Admin 账号尚未回填角色；回填需单独数据安全确认，不重建账号、
不读取密码、不修改已有邮箱或平台关联。
